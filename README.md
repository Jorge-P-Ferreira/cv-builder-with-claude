# CV Builder with Claude

A small template for writing and improving your CV with [Claude Code](https://claude.com/claude-code).

## What's inside

- **`guidelines.md`**: best practices for tech CVs. It covers section order, presenting yourself as a professional, concise bullets with numbers, keywords for ATS (Applicant Tracking Systems), and the STAR method for interviews. It ends with a checklist.
- **`CLAUDE.example.md`**: a template for the `CLAUDE.md` file that tells Claude about you and your goals.

## How to use it

1. Clone this repo.
2. Copy `CLAUDE.example.md` to `CLAUDE.md` and fill in your details.
3. Add your CV (LaTeX, Markdown or plain text). Your personal files are already listed in `.gitignore`.
4. Open the folder in Claude Code and ask it to review your CV against `guidelines.md`, tailor it to a job description, or run a mock interview.
